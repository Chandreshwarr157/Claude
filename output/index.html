HOW TO FINISH & EXPORT

  1. Add the character: cut out your Raven X-Suit skin (transparent PNG) and save it as output/assets/raven.png. Both thumbnails pick it up instantly — the dashed placeholder disappears.
  2. Edit the text: open thumbnail-1.html / thumbnail-2.html and change YOUR NAME HERE, the tagline, and the neon name to your channel/title.
  3. Export a crisp 1280×720 PNG: open the thumbnail file in Chrome → DevTools (F12) → Ctrl/Cmd + Shift + P → type "Capture node screenshot" and pick the .thumb element. (Or use any HTML-to-image tool.)
  4. Tip: keep faces & the LIVE badge inside the safe area — YouTube overlays a duration chip on the bottom-right corner.
